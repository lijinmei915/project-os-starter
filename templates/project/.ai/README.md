# AI 统一目录说明 (.ai/)

> 用途：说明 `.ai/` 统一目录的职责、边界和与项目文档的关系。
> 什么时候更新：`.ai/` 目录结构、规则映射方式、技能声明或 MCP 配置策略变化时。
> 不要写什么：具体业务规则、当前交接流水、工具私有配置。

本目录是 Project OS 推荐的跨工具、去中心化的 AI 原生资产存放点。
它旨在取代各自为战的 `.cursor/`, `.claude/`, `.github/` 等工具强绑定文件夹。

规则源头仍然是 `AGENTS.md`、`PROJECT.md` 和 `docs/DOCUMENTATION.md` 等项目文档。
`.ai/rules/` 只是面向 AI 工具的映射层，不另起一套规则源头。

## 目录结构

- **`rules/`**: 存放纯文本规则契约 (Markdown)。例如前端规范、后端架构约束等。AI 读取这些文件来理解 "你是谁、应该怎么写代码"。
- **`skills/`**: 存放通用技能配置。将 `scripts/` 中的执行动作与 AI 的 Trigger (触发提示词) 结合的声明文件。
- **`mcp/`**: 存放模型上下文协议 (Model Context Protocol) 相关的配置文件或轻量级服务端点。
