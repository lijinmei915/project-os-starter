# 错误模式记录

> 每次犯错后立即记录，防止同样的错误再犯。
>
> 用途：记录错误复盘和新增约束。
> 什么时候更新：误删、误改、误判、测试跑偏、规则失效时。
> 不要写什么：成功经验、无错误的普通进展、重复的 changelog 内容。

---

## 模板：如何记录一条教训

```markdown
### LES-001: 简述犯了什么错

- **日期**：YYYY-MM-DD
- **犯的错**：具体做了什么错误操作
- **根本原因**：为什么会犯这个错（流程缺失 / 理解偏差 / 工具限制）
- **造成的影响**：影响了什么、花了多久修复
- **加了什么规则**：为防止再犯，新增了什么约束或检查
```
