# 架构决策记录

> 记录重要技术或协作决策，防止重复讨论。
>
> 用途：记录"为什么这么定"。
> 什么时候更新：出现正式架构、产品、协作规则决策时。
> 不要写什么：当前状态流水、小修记录、临时 TODO。

---

## 模板：如何记录一条决策

```markdown
### DEC-001: 决策标题

- **日期**：YYYY-MM-DD
- **状态**：已决定 / 已废弃 / 讨论中
- **决定**：我们选择了 X
- **放弃**：考虑过 Y 和 Z，但没选
- **原因**：选 X 是因为……；不选 Y 是因为……
- **影响**：这个决定会影响到……
- **相关文件**：`path/to/file`
```
