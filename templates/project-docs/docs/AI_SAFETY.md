# AI 安全边界

> 用途：记录 AI 输出、提示词注入、工具调用、RAG 引用和人工复核边界。
> 什么时候更新：新增用户可见 AI 输出、Agent 工具调用、RAG 检索、评测集或 guardrails 策略变化时。
> 不要写什么：真实 prompt 密钥、临时调试记录、无法执行的笼统原则。

---

## 适用范围

本文件适用于：

- 面向用户展示 AI 生成内容
- Agent 可以调用工具、写文件、请求外部服务或执行高风险操作
- RAG / 知识库会检索、引用或总结外部资料
- 需要评测 prompt、模型输出或安全边界

没有 AI 输出、工具调用或 RAG 链路时，可以不生成本文件。

## RAG / 知识库边界

- 检索结果需要记录来源或引用。
- 不确定的答案应明确说明不确定，而不是补全事实。
- 用户私有数据、内部资料和公开资料需要区分来源。
- 召回失败时不得编造资料来源。

## 评测要求

| 类型 | 最小要求 |
|------|----------|
| Golden cases | 覆盖核心成功场景 |
| Regression cases | 覆盖曾经失败或容易退化的场景 |
| Safety cases | 覆盖提示词注入、越权工具调用和敏感信息泄露 |
